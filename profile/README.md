# QuantStrategyLab

Open-source building blocks for running systematic trading strategies: strategy packages, broker platform adapters, data snapshot pipelines, and runtime settings.

Experimental. Nothing here is financial advice, and live trading can lose money. You are responsible for your own configuration and orders.

Contributors: see the [documentation style guide](https://github.com/QuantStrategyLab/.github/blob/main/docs/STYLE_GUIDE.md).
